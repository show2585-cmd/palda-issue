# 팔다(PALDA) 체험 사이트 분석

- 레포지토리: https://github.com/show2585-cmd/palda-issue
- 분석 대상: https://palda-product-interview.highpixel2022.chatgpt.site/

팔다 제품 체험 사이트의 문제를 **UI/UX**와 **코드 기술** 두 분야로 나눠 정리한 HTML 보고서입니다.

## 구성

| 파일 | 내용 |
|---|---|
| `index.html` | 시작 화면. UI/UX 문제 또는 코드 기술 문제를 선택 |
| `ui-ux.html` | UI/UX 문제 |
| `tech.html` | 코드 기술 문제 |
| `assets/` | 공통 스타일·스크립트, 근거 캡처 이미지 |

## 보는 법

`index.html`을 브라우저로 열면 됩니다. 폰트(Pretendard)와 아이콘(lucide)은 CDN에서 불러옵니다.
